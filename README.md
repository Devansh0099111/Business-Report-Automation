## Project Demo

This project automates business reporting from raw Excel data.

### Input
Raw business data containing:
- Date
- Product
- Region
- Sales
- Expenses

### Automated Processing
Python processes the data and calculates:
- Total Sales
- Total Expenses
- Total Profit
- Profit Margin
- Total Orders
- Top Product
- Top Region

### Output
The system generates a formatted Excel report containing:
- KPI dashboard
- Product sales chart
- Conditional formatting
- Business insights
- Clean business data
