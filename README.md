# Business Report Automation

A Python-based business reporting system that reads raw Excel data, calculates business KPIs, generates insights, and creates a formatted Excel report automatically.

## Features

- Reads business data from Excel
- Calculates total sales
- Calculates total expenses
- Calculates total profit
- Calculates profit margin
- Counts total orders
- Identifies top-selling product
- Identifies highest-sales region
- Generates product sales chart
- Applies Excel formatting
- Applies conditional formatting
- Generates automated business insights

## Technologies

- Python
- Pandas
- OpenPyXL
- Excel

## How It Works

1. Business data is stored in an Excel file.
2. Python reads the Excel data using Pandas.
3. The script calculates business KPIs.
4. Product and regional sales are analyzed.
5. Business insights are generated.
6. OpenPyXL creates and formats the final Excel report.
7. The completed report is saved as `Business_Report.xlsx`.
